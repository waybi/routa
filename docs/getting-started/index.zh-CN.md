# 入门

本节面向你使用 Routa 的头 10 分钟：它是什么、应该选择哪个使用界面，以及完成设置后"可用"应该是什么样子。

## 选择你的使用界面

<div className="routa-doc-map">
  <a href="/routa/platforms/desktop">
    <strong>桌面端</strong>
    推荐大多数用户使用。从 GitHub Releases 安装，使用完整的工作区、会话、看板和团队 UI。
  </a>
  <a href="/routa/platforms/cli">
    <strong>CLI</strong>
    最适合以终端为主的使用方式。通过 <code>npm install -g routa-cli</code> 安装，然后从提示词、脚本编写或 ACP/运行时检视开始。
  </a>
  <a href="/routa/platforms/web">
    <strong>Web 端</strong>
    最适合基于浏览器的访问与自托管。当你需要浏览器运行时而非打包好的桌面端路径时，可从源码运行。
  </a>
</div>

如果你只想用最短路径完成一次成功的首次运行，请从 [快速开始](/quick-start) 入手，并选择 `Desktop` 或 `CLI`。

## 推荐阅读顺序

1. 阅读 [快速开始](/quick-start) 以选择 `Desktop`、`CLI` 或 `Web`。
2. 按照对应的平台页面完成安装和首次运行步骤。
3. 如果你仍需要一个 Provider 或模型，打开 [配置](/configuration)。
4. 当产品已经运行起来后，阅读 [核心概念](/core-concepts)。

## 在 Routa 中"开始"意味着什么

当你能够完成以下所有事项时，就算成功完成了上手：

- 创建或进入一个工作区
- 让一个 Provider 可用
- 挂接一个仓库
- 启动一个 `Session`、`Kanban` 流程或 `Team` 运行
