# 更新日志

Routa 目前没有为每个版本维护单一的手写更新日志页面。最有用的版本历史分散在以下几处：

- [GitHub Releases](https://github.com/phodal/routa/releases)
- [发布指南](/release-guide)
- [`docs/releases/`](/releases/v0.14.0-release-notes) 下的版本化发布说明

## 从这里开始

- 最新整理的发布说明：[v0.14.0 发布说明](/releases/v0.14.0-release-notes)
- 最新生成的技术更新日志：[v0.14.0 技术更新日志](/releases/v0.14.0-changelog)
- 更早发布的说明：
  - [v0.2.7 发布说明](/releases/v0.2.7-release-notes)
  - [v0.2.5 发布说明](/releases/v0.2.5-release-notes)

## 何时该读哪一份

- 如果你想要下载/安装的构建产物，请使用 GitHub Releases。
- 如果你想了解某个特定版本面向用户的变更，请使用发布说明。
- 如果你想要按提交分组的版本差异，请使用生成的技术更新日志。
- 如果你正在维护或发布 Routa，请使用发布指南。
