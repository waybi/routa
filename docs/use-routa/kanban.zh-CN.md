# 看板

看板是 Routa 的工作流驱动执行模式。

## 看板适合什么

当你希望具备以下能力时，选择看板：

- 明确的阶段，例如 backlog、todo、dev、review 和 done
- 可见的交付流，而不是一条自由形式的执行线程
- 由卡片移动和泳道策略触发的自动化

## 工作方式

看板不只是一个看板视图。在 Routa 中，泳道转换可以创建会话、将工作路由给 specialist，并为 `review` 和 `done` 等阶段执行交付检查。

## 最适合的场景

看板最适合：

- 工作需要稳定的交接流程
- 你希望 review 和 done 真的作为门禁发挥作用
- 多个任务需要经过同一套交付模型

## 差异点

看板里的编排边界是卡片及其泳道状态，而不是单个对话。这让 Routa 能够在工作流层应用策略、排队和特定阶段的 specialist 行为。
