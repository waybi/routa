# 使用 Routa

本节说明在 Routa 安装完成且至少一个 Provider 可用之后，如何选择合适的工作模式。

## 工作模式

| 模式 | 最适合 | 建议 |
| --- | --- | --- |
| [会话](/use-routa/sessions) | 快速开始工作、恢复上下文、维护一条主线程 | 默认选择 |
| [看板](/use-routa/kanban) | 可重复的交付流程、泳道自动化、评审门禁 | 流程驱动 |
| [团队](/use-routa/team) | 多 specialist 执行和显式协同 | 协同驱动 |

## 推荐顺序

1. 除非你已经确定需要工作流自动化或负责人驱动的委派，否则先从[会话](/use-routa/sessions)开始。
2. 当你需要交付阶段和可见的卡片流转时，切换到[看板](/use-routa/kanban)。
3. 当协同问题本身成为一等对象时，使用[团队](/use-routa/team)。
