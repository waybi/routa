# 会话

会话（Sessions）是 Routa 中默认的工作模式。

## 会话适用于什么场景

在以下情况下选择会话：

- 从提示词到产出有用工作的最短路径
- 一条之后可以恢复的主线程
- 灵活的编排方式，无需预先承诺某个看板或团队结构

## 工作原理

会话从一条可恢复的执行线程开始。当任务需要时，系统仍然可以引入
专家（specialists），但整个运行始于一个会话，而非一张固定的
工作流图。

## 典型的首次运行

1. 打开一个工作区。
2. 准备好一个可用的 Provider。
3. 关联一个仓库。
4. 启动一个 `Session`。
5. 给 Routa 一个具体的实现任务。

## 最适合的场景

会话通常是以下情况的正确选择：

- 仍需探索的功能开发
- 调试与恢复
- 一次性的实现任务
- 在新工作区中的首次成功运行
