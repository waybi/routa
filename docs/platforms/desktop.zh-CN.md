# 桌面端

对大多数 Routa 用户来说，桌面端是推荐的起点。

## 为什么选择桌面端

桌面端应用将完整的产品界面集中到一处：

- 工作区的创建与切换
- Provider 管理
- 会话、看板与团队流程
- 本地优先的持久化与执行

## 安装

从 [GitHub Releases](https://github.com/phodal/routa/releases) 下载适用于你所在平台的最新桌面端构建版本。

## 安装之后

请按以下顺序操作：

1. 创建一个工作区。
2. 打开 Provider 设置，让至少一个 Provider 可用。
3. 关联一个代码仓库。
4. 从一个 `Session` 开始，让 Routa 检查该仓库或为其规划工作。
5. 当你需要任务拆解与泳道自动化时，转向 `Kanban`。

## 最适合的场景

在以下情况下选择桌面端：

- 你希望在一个 UI 中获得完整的产品模型
- 你需要面向非贡献者最简单的首次运行路径
- 你需要本地优先的存储与捆绑式桌面端分发
