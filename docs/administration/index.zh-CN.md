# 管理

管理涵盖 Routa 的运维层面：如何运行它、发布它，并让运行时各个界面对团队保持可用。

## 这里所说的「管理」是什么

本章节面向维护者、自托管用户，以及所有管理 Routa 环境的人，而不仅仅是每次只使用单个会话的人。

## 主要主题

- [自托管](/administration/self-hosting)：在你自己的环境中运行 Web / 运行时界面
- [部署](/deployment)：桌面端、CLI 和 Web 端的分发路径
- [发布指南](/release-guide)：在 crates.io、npm 和 GitHub Releases 上发布产物
- [配置](/configuration)：影响运行时行为的 Provider、模型和环境变量
