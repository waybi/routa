# 部署

Routa 中的部署目前涵盖两个相关方面：

- 分发可下载的产物，例如桌面端和 CLI 二进制文件
- 在你自己的环境中运行或发布 Web/运行时界面

## 部署路径

| 路径 | 当前含义 |
| --- | --- |
| 桌面端分发 | 通过 GitHub Releases 发布的打包应用构建 |
| CLI 分发 | 通过 npm 和 crates.io 进行包发布 |
| Web 运行时 | 从源码进行本地开发或自托管部署 |
