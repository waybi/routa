## 5 分钟上手

如果你正在评估 Routa，不要一上来就把所有内容都读一遍。选定一条路径，
并以拿到一个真实结果为目标：

<div className="routa-start-grid">
  <div className="routa-start-card">
    <span className="routa-start-card__badge">推荐</span>
    <h3>桌面端</h3>
    <p>最适合大多数用户：以最少的配置工作量获得完整的 Routa 产品体验。</p>
    <code>Download from GitHub Releases</code>
    <p>创建一个工作区，附加一个代码仓库，然后从会话开始。</p>
    <a className="routa-inline-link" href="/routa/platforms/desktop">打开桌面端指南</a>
  </div>
  <div className="routa-start-card">
    <span className="routa-start-card__badge">终端优先</span>
    <h3>CLI</h3>
    <p>当你的代码仓库已经在终端中打开，并且想要最短路径时最合适。</p>
    <code>npm install -g routa-cli</code>
    <p>然后运行 <code>routa -p "Explain this repository"</code>。</p>
    <a className="routa-inline-link" href="/routa/platforms/cli">打开 CLI 指南</a>
  </div>
  <div className="routa-start-card">
    <span className="routa-start-card__badge">自托管</span>
    <h3>Web 端</h3>
    <p>最适合在你自己的环境或内部部署中通过浏览器访问。</p>
    <code>npm run dev</code>
    <p>当你想要浏览器界面而非打包应用时，使用这条路径。</p>
    <a className="routa-inline-link" href="/routa/platforms/web">打开 Web 端指南</a>
  </div>
</div>

## 你可以做什么

<div className="routa-grid">
  <div className="routa-card routa-card--blue">
    <h3>理解代码库</h3>
    <p>
      使用会话来理解一个新仓库、检查架构，并在之后从一条主线程
      恢复工作。
    </p>
  </div>
  <div className="routa-card routa-card--orange">
    <h3>运行交付流程</h3>
    <p>
      当工作需要明确的阶段、按泳道分配专家的自动化，以及真正能强制保证质量的
      评审门或完成门时，使用看板。
    </p>
  </div>
  <div className="routa-card routa-card--green">
    <h3>协调专家</h3>
    <p>
      当协调问题本身就是头等大事，并且工作能从一个负责人跨专业派发子会话中受益时，
      使用团队。
    </p>
  </div>
</div>
