# DOCX 阅读器功能完整性清单

一份按功能领域组织的 DOCX 阅读器与渲染器能力的结构化清单。本跟踪文档聚焦于 Walnut 协议对齐工作中识别出的生产就绪度缺口。

## 概述

**完整度**：约 90%（协议层面已接近功能完备；渲染/视觉保真度是下一个攻坚方向）

**关键状态**：
- ✅ 协议等价性已针对所有已提交固件（fixture）及真实世界中文样本锁定对齐 Walnut
- ✅ 核心渲染（文本/样式/表格/图片/页眉/页脚/分节）已达生产就绪
- ⏳ 视觉布局深度（浮动对象排序/文字环绕距离/效果/形状样式）以及图表负载长尾为下一步
- ⏳ 长尾边界情况（罕见的样式/表格/页眉组合）

## 功能领域

### 1. 核心协议与读取

**状态**：100% 完成

- [x] 文档结构（正文、分节、页眉/页脚）
- [x] 带 `basedOn` 链与继承的段落样式
- [x] 运行（run）样式（字体、字号、加粗、斜体、下划线、颜色、突出显示、配色方案）
- [x] 表格结构（行、列、跨度、合并、嵌套）
- [x] 列表与编号（项目符号、自动编号、列表层级）
- [x] 超链接与书签
- [x] 内容控件（文本、富文本、下拉框、日期选择器）
- [x] 修订追踪（带元数据的插入、删除）
- [x] 批注、脚注/尾注
- [x] 分节页面设置（页边距、页面大小、分栏、分页符）
- [x] 图片引用与锚点
- [x] 图表引用
- [x] 真实世界怪异情形（Word 生成器 vs OpenXML 规范）

**剩余**：协议层面无

## 建议的后续步骤

### 高优先级（阻塞预览界面）
1. **浮动环绕与效果** — 完成图片/形状定位及视觉效果，以实现真实的文档渲染
2. **图表负载渲染** — 从引用迈向实际的图表可视化
3. **更广泛的真实世界固件** — 针对更大的生产语料库进行测试，以发现遗漏的边界情况

### 中优先级（打磨）
4. **域代码** — 从基础页码扩展到日期/时间/交叉引用
5. **大纲/目录** — 交互式目录生成
6. **高级表格样式** — 镶边行、条件样式、合并模式

### 较低优先级（长尾）
7. **组合对象与连接符** — 罕见的绘图特性
8. **高级形状效果** — 阴影、3D、倒影（仅视觉）
9. **修订 UI** — 接受/拒绝修改的界面
