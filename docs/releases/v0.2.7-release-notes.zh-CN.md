# Release v0.2.7 - 桌面端工作流、看板自动化与团队运行稳定性

**发布日期**：2026-03-25  
**标签**：`v0.2.7`

## 概述

Routa Desktop v0.2.7 专注于让桌面端工作流在多 Agent 协作场景下更可靠、更易操作。本次发布改进了 ACP 会话回放与流式传输，升级了看板泳道自动化与看板可配置性，收紧了团队运行（Team Run）的协调体验，并以更一致的品牌色板刷新了桌面端的视觉系统。

与 `v0.2.6` 相比，本次发布还包含针对 Tauri 打包与校验的发布流水线加固，降低了跨平台桌面交付的阻力。

## 核心亮点

### 1. 更可靠的 ACP 会话流式传输与回放

- 改进了 Claude SDK 会话的增量 SSE 流式传输
- 重连后会话事件回放更持久
- 新增 runner 感知的会话绑定与独立 runner 支持
- 减少了 Trace 事件、Rust 会话状态与 UI 渲染之间的 transcript 漂移
- 新增共享会话 transcript 端点，使历史加载更一致

用户影响：
- 活跃会话在重连后恢复得更干净
- 长时间运行的桌面端会话能更一致地展示 transcript 更新
- 流式执行期间，Trace 与会话视图保持更好的对齐

### 2. 更强的看板自动化与看板可配置性

- 为看板泳道自动化新增 A2A 传输支持
- 在 Rust 侧持久化看板自动化的泳道历史
- 将看板列设为一等可配置单元
- 新增阶段结构编辑，并改进了看板设置选择器
- 将更多泳道与 YAML 控件移入看板设置
- 在看板设置中新增清空全部任务的操作
- 新增卡片评论，并改进了进度/详情同步

用户影响：
- 看板更易适配真实工作流，而非固定列结构
- 自动化泳道流转更可观测、更持久
- 看板详情视图与后台任务进度贴合得更紧密

### 3. 更好的团队运行协调流程

- 在团队运行中新增实时会话泳道
- 将成员会话更直接地嵌入协调信息流
- 恢复了团队运行历史与持久化
- 修复了 lead 会话交接、运行刷新与委派成员映射
- 改进了会话切换并移除了不必要的轮询
- 恢复了主页输入的提及（mentions）功能与团队启动的提问处理

用户影响：
- 运行进行时，团队编排更易跟踪
- Lead 与成员会话之间的关系更清晰
- 团队运行能更可靠地在刷新与延迟更新中存续

### 4. 更整洁的桌面端 UI 与设置体验

- 在工作区、聊天、设置与看板各界面统一 ACP Provider 下拉框
- 简化了设置面板结构并内嵌了 Provider 区块
- 对齐了看板设置选择器并精简了布局
- 为仓库选择器（Repo Picker）新增内联分支与重置操作
- 刷新了工作区/团队页头与共享外壳结构
- 扩展了共享品牌色系统，并使桌面端主题与之对齐

用户影响：
- 桌面端各页面间控件不一致的情况减少
- 更快地访问 Provider 与仓库相关操作
- 工作区、Trace 与团队视图之间的视觉层级更一致

### 5. 桌面端发布与打包加固

- 稳定了 Tauri 发布校验
- 修复了本地 `3210` 工作流的桌面端静态目录解析
- 恢复了静态前端导出构建的可靠性

用户影响：
- 桌面端构建在发布校验期间更可预测
- 本地打包与 Rust 后端支持的桌面端流程行为更一致

## 技术摘要

本次发布中值得关注的实现区域：

- `src/core/acp/` 与 `crates/routa-core/src/acp/`：会话流式传输、回放与 runner 支持
- `src/core/kanban/`、`crates/routa-core/src/rpc/methods/kanban/` 与 `crates/routa-server/src/api/kanban.rs`：看板可配置性与泳道自动化
- `src/app/workspace/[workspaceId]/team/` 及相关 UI 模型：团队运行协调
- `src/client/components/`：统一下拉框、设置结构重组、仓库选择器操作与桌面端外壳细化
- `apps/desktop/src-tauri/` 及发布工作流更新：打包稳定性
