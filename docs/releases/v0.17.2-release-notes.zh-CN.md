# Routa Desktop v0.17.2

## 概要

Routa Desktop v0.17.2 包含来自 `v0.17.1..a6a9dd4fbbe7d820368458afc1ece993301c5234` 的 44 个非合并提交。

### 亮点

- **桌面端与发布：** 桌面端、CI 和发布工作流的变更改进了打包、可选签名、发布校验以及跨平台运行时行为。
- **看板与任务交付：** 看板和任务交付的变更让卡片、评审、PR、diff 以及由 worktree 驱动的交接更易于检视。
- **CLI 与开发者工具：** CLI 和开发者工具的更新扩展了图分析、仓库安全检查、Skill、Hook 以及诊断能力。
- **Harness 与架构：** Harness 和架构方面的工作增加了更强的仓库分析、适应度函数检查、生成式 playbook 以及演进历史。
- **会话与 Agent 运行时：** 会话和 Agent 运行时的更新改进了 Trace 恢复、Provider 行为、流式传输以及长时运行的 Agent 执行。

变更涉及的顶层区域：`.gitignore`、`apps`、`crates`、`docs`、`docusaurus.config.js`、`resources`、`scripts`、`sidebars.js`。

### 升级说明

- 从约定式提交（conventional commit）标记中未发现破坏性变更。
- 在发布前，请先审阅与发布、安装程序、签名、打包、迁移或 schema 相关的技术变更日志条目。
