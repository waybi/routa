# 发布 v0.2.5 - Tauri 桌面端用户体验改进

**发布日期**：2026-03-15  
**标签**：`v0.2.5`  
**适应度函数评分**：100% ✅

## 概述

本次发布聚焦于改进 Tauri 桌面端应用的用户体验，包括增强的菜单导航、键盘快捷键，以及修复看板工作流中的关键生命周期问题。

## 🎯 核心亮点

### 1. 增强的桌面端菜单系统

**新增「导航」菜单**及键盘快捷键：
- 仪表盘（`Cmd+1` / `Ctrl+1`）
- 看板（`Cmd+2` / `Ctrl+2`）
- Agent Trace（`Cmd+3` / `Ctrl+3`）
- 设置（`Cmd+,` / `Ctrl+,`）

**工具模式切换**已移至「视图」菜单：
- 在精简模式（7 个工具）与完整模式（34 个工具）之间切换
- 键盘快捷键：`Cmd+Shift+T` / `Ctrl+Shift+T`
- 可从任意页面访问，而不仅限于会话页面

**改进的菜单结构**：
```
File
├── Reload (Cmd+R)
└── Quit (Cmd+Q)

View
├── Toggle Developer Tools (Cmd+Option+I)
└── Toggle Tool Mode (Essential/Full) (Cmd+Shift+T)  ← NEW

Navigate  ← NEW MENU
├── Dashboard (Cmd+1)
├── Kanban Board (Cmd+2)
├── Agent Traces (Cmd+3)
└── Settings (Cmd+,)

Tools
├── Install Agents... (Cmd+Shift+I)
└── MCP Tools (Cmd+Shift+M)
```

### 2. 修复看板仓库生命周期

**问题**：用户在尝试从看板页面添加仓库时遇到了导航死循环。

**解决方案**：用内联的 RepoPicker 组件替换了失效的「在设置中添加」链接。

**收益**：
- ✅ 无需页面跳转
- ✅ 直接从看板克隆/选择仓库
- ✅ 成功添加后自动刷新
- ✅ 与 HomeInput 的用户体验模式保持一致

### 3. Tauri 静态路由处理

修复了 Tauri 桌面端应用中非工作区页面的路由：
- `/traces` → Agent Trace 查看器
- `/mcp-tools` → MCP Tools 页面
- `/settings` → 设置页面

所有静态页面现在都能正确加载，不再回退到首页。

## 🚀 升级说明

### 面向用户

1. **下载新的 DMG**（macOS）：
   ```bash
   # Build from source
   cd apps/desktop
   npm run build
   ```

2. **安装 DMG**：
   - 打开 `target/release/bundle/dmg/Routa Desktop_0.2.5_aarch64.dmg`
   - 拖入「应用程序」文件夹

3. **体验新功能**：
   - 尝试键盘快捷键：`Cmd+1`、`Cmd+2`、`Cmd+3`
   - 切换工具模式：`Cmd+Shift+T`
   - 直接从看板页面添加仓库

### 面向开发者

1. **拉取最新更改**：
   ```bash
   git pull origin main
   git checkout v0.2.5
   ```

2. **安装依赖**：
   ```bash
   npm install
   ```

3. **在开发模式下运行**：
   ```bash
   cd apps/desktop
   npm run tauri dev
   ```
